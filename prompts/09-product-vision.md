# CVLab AI - Product Vision

## 1. Product Overview

CVLab AI is a digital career-development platform focused on helping users:

- Create professional CVs
- Improve existing CVs using AI
- Create cover letters
- Analyse CV compatibility with job descriptions
- Practice technical and professional tests
- Practice job interviews
- Receive AI-powered career guidance
- Manage their professional profile
- Purchase and consume platform credits

The initial target market is Mozambique and other Portuguese-speaking markets.

The product must be designed from the beginning to support international expansion.

---

# 2. Product Mission

Help job seekers become more prepared, more competitive and more confident when applying for employment opportunities.

---

# 3. Product Principles

The platform must always prioritize:

1. Simplicity
2. Trust
3. Professional quality
4. Accessibility
5. Security
6. Fair pricing
7. Transparency
8. Measurable improvement

---

# 4. Main User Types

## USER

A normal platform customer.

Can:

- Create account
- Manage profile
- Create CVs
- Edit CVs
- Use AI features
- Take tests
- Practice interviews
- Buy credits
- View history

---

## ADMIN

Platform administrator.

Can:

- Manage users
- Manage tests
- Manage questions
- Manage credit packages
- View payments
- View platform statistics
- Manage AI prompts
- Manage content
- Review system logs

---

## SUPER_ADMIN

System-level administrator.

Can:

- Manage administrators
- Configure system settings
- Access sensitive operational settings
- Manage integrations
- Manage permissions

# 7. Future Expansion

The architecture must support future features such as:

- Job marketplace
- Job matching
- Recruiter accounts
- Public professional profiles
- Employer dashboards
- Training courses
- Certifications
- Skill assessments
- Career coaching
- eMola
- Bank payments
- Card payments
- International currencies

These features should not be implemented in the MVP unless explicitly requested.

---

# 8. MVP Rule

Do not over-engineer the first release.

The MVP must focus on:

- Authentication
- Profile
- CV creation
- CV editing
- AI improvement
- Credits
- M-Pesa payments
- Tests
- Interview practice
- History
- Admin panel

---

# 9. UX Philosophy

The user should always understand:

- What they are doing
- How much it costs
- How many credits they have
- What they will receive
- What happened after an action

Never hide important costs.

---

# 10. Business Philosophy

The platform operates under a credit-based model.

Credits are purchased using supported payment methods.

Credits are consumed when users access paid features.

Every credit movement must be auditable.

---

# 11. Product Quality

The platform must feel like a professional SaaS product.

Avoid:

- Amateur interfaces
- Broken layouts
- Unclear messages
- Inconsistent terminology
- Unexplained errors
- Hidden costs
- Unnecessary complexity

---

# 12. Product Language

Primary language:

Portuguese.

The architecture must support internationalization.

Future languages:

English

French

Spanish

---

# 13. Currency

Initial currency:

MZN / MT

Future currencies must be supported through a currency abstraction layer.

Never hardcode currency-specific business logic throughout the application.

---

# 14. Product Success Metrics

Track:

- Registered users
- Active users
- CVs created
- CV improvements
- Tests completed
- Interviews completed
- Credits purchased
- Credits consumed
- Revenue
- Conversion rate
- Retention
- Average credits consumed per user

---

# 15. Golden Rule

Every feature must provide clear value to the user's professional development.

Do not build features simply because they are technically interesting.
