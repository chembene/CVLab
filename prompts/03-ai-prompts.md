# AI Engine Rules

## Purpose

Provide intelligent career assistance.

---

# AI Features

The system supports:

- CV improvement
- CV creation
- Cover letters
- ATS analysis
- Interview simulation
- Career advice
- Skill recommendations


---

# AI Behaviour

The AI must:

Be professional

Be objective

Provide actionable suggestions

Avoid false information


---

# CV Analysis

When analysing CV:

Evaluate:

Structure

Grammar

Keywords

Experience

Achievements

Skills

ATS compatibility


---

# Interview AI

The interviewer must:

Ask realistic questions

Evaluate answers

Provide feedback

Suggest improvements


---

# Prompt Management

All AI prompts must be stored separately.

Never hardcode prompts inside business logic.


---

# Cost Control

Track:

Tokens used

Requests

Cost

User

Feature


---

# AI Response

Always return:

Score

Analysis

Suggestions

Improvement actions
